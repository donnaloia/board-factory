How to use this page

  1. Propose — Pick which image defines the frame (a live panel tile or an upload) and run vision. Candidates appear on the left.
  2. Refine — The frame extraction region (dashed brass rectangle) is where we slice rim sprites from your source image — not a “focus” on gameplay art. Drag corners to resize it. Magenta tint = rim (kept); cyan tint = hole (repainted on panels). The ring thickness slider adjusts rim width.
  3. Typical-panel preview — The thumbnail is interior art and rim together (not art alone): content scaled under the hole plus the new chrome at catalog size; it tracks Refine.
  4. Commit — “Adopt frame” saves that rim for the board; optional reapply redraws panel interiors. Vision helps find the frame region; the built pipeline still builds a nine-slice rim (corners + edges that tile), which is why crop lines look straight — that keeps pixel art sharp at any panel size.

      Commit — adopt & reapply

      Adopting writes the new frame into workspace/frames/house/. With Reapply to all panels, every applicable panel interior is repainted under the new rim. With Regenerate frame source panel only (panel sources only), just that tile is inpainted and you return to the board editor when it finishes. Each panel keeps a snapshot in history tagged frame_rework_pre when reapply runs, so you can roll back.
