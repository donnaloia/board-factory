Layout spec moved

The layout spec is now generated live from the database (`board_games.body_json`). There is no static HTML version anymore — keeping a hand-authored copy in sync with the catalog turned out to be a recipe for drift, which was the exact problem the spec was supposed to prevent.

Run make up and visit http://localhost:8473/spec.

Need to edit the spec? Use the web UI for everything geometric, and docs/spec_prose.md for the explanatory prose sections.

This file remains as a redirect stub for old links. It will be removed in a future cleanup.
